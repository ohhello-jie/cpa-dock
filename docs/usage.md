# 使用与恢复

## 配置与文件

首次使用时，点击安装 CPA，按向导填写配置。已有 CPA 的用户可在设置中选择程序和 `config.yaml`。

| 文件 | 位置 |
| --- | --- |
| 启动器设置 | `%AppData%\CPALauncher\settings.json` |
| 默认 CPA 安装目录 | CPA Dock 程序同级的 `cpa\` |
| 凭证目录 | CPA 配置中的 `auth-dir` |
| 日志目录 | 根据运行配置确定，可从设置页打开 |

保存设置时会保留上一份备份，设置文件损坏时尝试恢复。

## 凭证导入

选择或拖入 JSON 凭证文件即可导入。导入前会检查 JSON 格式，覆盖同名文件时请求确认，并将上一份保存为 `.json.bak`。

由 CPA Dock 启动的 CPA 正在运行时，导入前会确认重启，重启后加载新凭证。外部运行的 CPA 需在原程序中重启；已停止的 CPA 在下次启动时加载新凭证。

恢复凭证时，停止 CPA，将 `.json.bak` 备份复制回原文件名，再启动 CPA。

## 更新与恢复

设置页可分别检查 CPA 和 CPA Dock 的更新。更新包在解压前核对 SHA256；缺少校验值或校验不一致时，更新会停止。

CPA 更新后会检查启动状态，检查失败时恢复旧版。CPA Dock 更新中断后，会在下次启动时尝试恢复；启动失败时，可从安装目录的 `.cpa-update-*` 文件夹运行 `恢复旧版.cmd`。

旧版自动更新失败时，退出 CPA Dock，将新版解压覆盖到原目录，再运行 `CPA Dock.exe`。保留原有 `cpa` 目录和配置文件。

## 退出

退出 CPA Dock 时，可选择停止 CPA 或保留服务。外部启动的 CPA 需在原程序中停止或重启。
